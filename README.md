# Вариант 3. Решение заданий

## Задание 1

**Условие:**
Вычислить логическое выражение: \((X > 3) \lor (X < 3) \lor (X < 1)\) при \(X = 3\).

**Решение:**
1. Подставим значение \(X = 3\) в каждую часть выражения:
   - \((X > 3) \Rightarrow (3 > 3)\) — **Ложь (0)**
   - \((X < 3) \Rightarrow (3 < 3)\) — **Ложь (0)**
   - \((X < 1) \Rightarrow (3 < 1)\) — **Ложь (0)**
2. Применим операцию логического ИЛИ (дизъюнкцию). Дизъюнкция ложна только тогда, когда все её операнды ложны.
3. Получаем: \(0 \lor 0 \lor 0 = 0\) (Ложь).

**Ответ:** Ложь (0).

## Задание 2

**Условие:**
Если производная функции в точке равна нулю и вторая производная этой функции в той же точке отрицательна, то данная точка есть точка локального максимума функции.

**Решение:**
Данное утверждение является **истинным** и представляет собой классическую теорему из математического анализа (достаточное условие экстремума).

**Ответ:** Утверждение верно.
