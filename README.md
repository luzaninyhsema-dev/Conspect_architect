# Конспект: Алгебра высказываний

## 1. Высказывания и операции над ними

**Высказывание** — повествовательное предложение, о котором можно однозначно сказать, истинно оно или ложно. Побудительные, вопросительные и восклицательные предложения высказываниями не являются.

Высказывания бывают:
- **простые (элементарные)** — содержат одно утверждение без логических операций;
- **сложные (составные)** — состоят из простых высказываний, соединённых логическими операциями.

**Основные логические операции:**
- **инверсия (отрицание, НЕ)** — меняет значение высказывания на противоположное;
- **дизъюнкция (ИЛИ)** — истинна, если хотя бы одно из высказываний истинно;
- **конъюнкция (И)** — истинна только тогда, когда оба высказывания истинны;
- **импликация (ЕСЛИ… ТО)** — ложна лишь в случае, когда посылка истинна, а следствие ложно;
- **эквиваленция (ТОГДА И ТОЛЬКО ТОГДА, КОГДА)** — истинна, когда оба высказывания имеют одинаковые значения.

---

## 2. Формулы логики высказываний

**Формула логики высказываний** — сложное высказывание, образованное из простых с помощью логических операций.

Все возможные значения формулы описываются таблицей истинности. Если формула содержит $n$ элементарных высказываний, она принимает $2^n$ комбинаций значений.

**Виды формул по истинности:**
- **тождественно истинная** — принимает значение «истина» при любых значениях переменных;
- **тождественно ложная** — принимает значение «ложь» при любых значениях переменных.

**Приоритет логических операций:**
1. отрицание;
2. конъюнкция;
3. дизъюнкция;
4. импликация и эквиваленция.

---

## 3. Равносильные формулы

Две формулы называются **равносильными**, если при любых значениях переменных они принимают одинаковые значения.

**Основные равносильности:**
- закон двойного отрицания;
- коммутативные, ассоциативные и дистрибутивные законы;
- законы поглощения;
- законы де Моргана;
- законы идемпотентности;
- свойства констант (0 и 1);
- выражения импликации и эквиваленции через базовые операции.

---

## 4. Нормальные формы

**Элементарная конъюнкция** — конъюнкция высказываний и их отрицаний.  
**Элементарная дизъюнкция** — дизъюнкция высказываний и их отрицаний.

**Дизъюнктивная нормальная форма (ДНФ)** — дизъюнкция элементарных конъюнкций, равносильная исходной формуле.  
**Конъюнктивная нормальная форма (КНФ)** — конъюнкция элементарных дизъюнкций, равносильная исходной формуле.

**Совершенная ДНФ (СДНФ)** — ДНФ, удовлетворяющая условиям:
- каждая элементарная конъюнкция содержит все переменные формулы;
- все конъюнкции различны;
- в одной конъюнкции нет переменной и её отрицания одновременно;
- переменная не повторяется в одной конъюнкции.

**Совершенная КНФ (СКНФ)** — КНФ, аналогичная СДНФ по требованиям, но для дизъюнкций.

СДНФ существует для любой не тождественно ложной формулы, СКНФ — для любой не тождественно истинной формулы; обе формы единственны.

---

## 5. Логическое следование и условия

Формула $H$ является **логическим следствием** формул $F_1, \dots, F_m$, если при всех наборах значений переменных, где все $F_i$ истинны, формула $H$ также истинна. Проверяется через таблицы истинности.

Для теоремы вида $X \to Y$:
- $Y$ — необходимое условие для $X$ (если $X$ истинно, то $Y$ обязано быть истинным);
- $X$ — достаточное условие для $Y$ (истинности $X$ достаточно для истинности $Y$).

---

## 6. Решение логических задач

Метод решения:
1. Обозначить элементарные высказывания логическими переменными.
2. Записать условия задачи в виде логических формул.
3. Упростить формулу с помощью равносильных преобразований.
4. Проанализировать результат для получения ответа.

# Вариант 3. Решение заданий

## Задание 1

**Условие:**
Вычислить логическое выражение: \((X > 3) or (X < 3) or (X < 1)\) при \(X = 3\).

**Решение:**
1. Подставим значение \(X = 3\) в каждую часть выражения:
   - \((X > 3) \=> (3 > 3)\) — **Ложь (0)**
   - \((X < 3) \=> (3 < 3)\) — **Ложь (0)**
   - \((X < 1) \=> (3 < 1)\) — **Ложь (0)**
2. Применим операцию логического ИЛИ (дизъюнкцию). Дизъюнкция ложна только тогда, когда все её операнды ложны.
3. Получаем: \(0 or 0 or 0 = 0\) (Ложь).

**Ответ:** Ложь (0).

## Задание 2

**Условие:**
Если производная функции в точке равна нулю и вторая производная этой функции в той же точке отрицательна, то данная точка есть точка локального максимума функции.

**Решение:**
Данное утверждение является **истинным** и представляет собой классическую теорему из математического анализа.

**Ответ:** Утверждение верно.
