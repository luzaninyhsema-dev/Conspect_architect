# Конспект по алгебре высказываний

## 1. Базовые понятия

Высказывание — это предложение, про которое можно точно сказать, правда это или ложь. Не подходят вопросы, приказы, восклицания.

Типы высказываний:
* простые — одно утверждение, без связок;
* сложные — из нескольких простых, соединённых логическими связками.

Логические операции:
* НЕ (инверсия) — переворачивает значение;
* ИЛИ (дизъюнкция) — даёт истину, если хоть одно из высказываний истинно;
* И (конъюнкция) — истина только если оба высказывания истинны;
* ЕСЛИ… ТО (импликация) — ложна только когда из истины следует ложь;
* ТОГДА И ТОЛЬКО ТОГДА (эквиваленция) — истина, когда значения совпадают.

---

## 2. Формулы и их свойства

Формула — сложное высказывание из простых и операций.

Число строк в таблице истинности: $2^n$, где $n$ — число переменных.

По поведению формулы делят на:
* тождественно истинные — всегда 1;
* тождественно ложные — всегда 0.

Порядок выполнения операций:
1. отрицание;
2. конъюнкция;
3. дизъюнкция;
4. импликация и эквиваленция.

---

## 3. Равносильность

Равносильные формулы — дают одинаковые результаты при любых значениях переменных.

Ключевые равносильности:
* двойное отрицание;
* переместительные (коммутативные) законы;
* сочетательные (ассоциативные) законы;
* распределительные (дистрибутивные) законы;
* законы поглощения;
* законы де Моргана;
* идемпотентность;
* работа с константами 0 и 1;
* замена импликации и эквиваленции через другие операции.

---

## 4. Нормальные формы

Элементарная конъюнкция — набор переменных и их отрицаний, соединённых И.  
Элементарная дизъюнкция — набор переменных и их отрицаний, соединённых ИЛИ.

ДНФ — дизъюнкция элементарных конъюнкций.  
КНФ — конъюнкция элементарных дизъюнкций.

СДНФ — ДНФ с условиями:
* в каждой конъюнкции есть все переменные;
* нет повторяющихся конъюнкций;
* нет переменной и её отрицания в одной конъюнкции;
* нет повторов переменной в одной конъюнкции.

СКНФ — КНФ с аналогичными требованиями, но для дизъюнкций.

СДНФ есть у любой не тождественно ложной формулы.  
СКНФ есть у любой не тождественно истинной формулы.  
Обе совершенные формы — единственные для своей формулы.

---

## 5. Логическое следование и условия

$H$ — логическое следствие $F_1, \dots, F_m$, если при всех значениях, где все $F_i = 1$, также $H = 1$.

Для $X \to Y$:
* $Y$ — необходимое условие для $X$;
* $X$ — достаточное условие для $Y$.

---

## 6. Как решать логические задачи

Шаги:
1. Ввести переменные для простых высказываний.
2. Записать условия как логические формулы.
3. Упростить выражения равносильными преобразованиями.
4. Сделать вывод на основе упрощённой формулы.

# Вариант 3. Решение заданий

## Задание 1

**Условие:**
Вычислить логическое выражение: \((X > 3) or (X < 3) or (X < 1)\) при \(X = 3\).

**Решение:**
1. Подставим значение \(X = 3\) в каждую часть выражения:
   - \((X > 3) \=> (3 > 3)\) — **Ложь (0)**
   - \((X < 3) \=> (3 < 3)\) — **Ложь (0)**
   - \((X < 1) \=> (3 < 1)\) — **Ложь (0)**
2. Применим операцию логического ИЛИ (дизъюнкцию). Дизъюнкция ложна только тогда, когда все её операнды ложны.
3. Получаем: \(0 or 0 or 0 = 0\) (Ложь).

**Ответ:** Ложь (0).

## Задание 2

**Условие:**
Если производная функции в точке равна нулю и вторая производная этой функции в той же точке отрицательна, то данная точка есть точка локального максимума функции.

**Решение:**
Данное утверждение является **истинным** и представляет собой классическую теорему из математического анализа.

**Ответ:** Утверждение верно.
